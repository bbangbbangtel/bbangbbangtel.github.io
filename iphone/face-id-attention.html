아이폰 Face ID 등록하고 주시 지각·마스크 설정 확인하기

얼굴 인증으로 아이폰 잠금 해제와 앱 로그인·결제를 안전하고 빠르게 처리합니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 iPhone 모델, 국가·지역, 통신사, 언어와 iOS 버전에 따라 달라질 수 있습니다. 설정 앱의 검색창에서 기능 이름을 검색하면 현재 기기에서 제공되는 메뉴를 찾기 쉽습니다.

이럴 때 유용합니다

  • 아이폰 잠금과 금융 앱을 얼굴로 인증할 때
  • 안경이나 마스크 사용 환경에서 인식률을 조절할 때
  • 화면을 보고 있을 때만 잠금 해제되도록 보안을 높일 때

설정하고 사용하는 순서

  1. 설정에서 Face ID 및 암호를 열고 기기 암호를 입력합니다.
  2. Face ID 설정을 눌러 안내에 따라 얼굴을 두 번 스캔합니다.
  3. iPhone 잠금 해제·결제·암호 자동 완성에 사용할 항목을 선택합니다.
  4. 주시 지각 기능과 마스크를 쓴 상태로 Face ID 옵션을 확인합니다.
  5. 인식 문제가 반복되면 카메라를 닦고 Face ID를 재설정합니다.

안전하고 편리하게 사용하는 팁

  • 선글라스와 얼굴을 가리는 물건은 인식에 영향을 줄 수 있습니다.
  • 주시 지각을 끄면 편리할 수 있지만 보안 수준이 낮아질 수 있습니다.
  • 기기 암호는 Face ID가 작동하지 않을 때 필요한 최종 보안 수단입니다.

지원 기기와 주의사항

Face ID와 마스크 지원은 TrueDepth 카메라가 있는 iPhone 모델 및 iOS에 따라 다릅니다.

중요: Apple 계정, 개인정보, 통화 녹음, 결제, 초기화와 통신서비스에 영향을 주는 작업은 화면 안내와 관련 법률을 확인하고 중요한 자료를 먼저 백업하세요.

함께 보면 좋은 기능

🙈

앱 잠그기·가리기

사진·메신저 등 다른 사람이 열면 곤란한 앱에 추가 인증을 요구하거나 화면에서 숨깁니다.

🔑

암호·패스키

웹사이트와 앱 로그인 정보를 암호화해 보관하고 Face ID로 자동 완성하며 보안 상태를 확인합니다.

🛡️

도난당한 기기 보호

기기 암호를 훔쳐본 사람이 아이폰을 가져가도 중요 계정과 금융 정보 변경을 어렵게 만듭니다.
