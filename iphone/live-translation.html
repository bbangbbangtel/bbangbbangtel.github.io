아이폰 전화·메시지·FaceTime에서 실시간 번역 사용하기

서로 다른 언어를 사용하는 사람과 통화하거나 메시지를 주고받을 때 번역을 함께 표시합니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 iPhone 모델, 국가·지역, 통신사, 언어와 iOS 버전에 따라 달라질 수 있습니다. 설정 앱의 검색창에서 기능 이름을 검색하면 현재 기기에서 제공되는 메뉴를 찾기 쉽습니다.

이럴 때 유용합니다

  • 외국인 고객과 메시지로 상담할 때
  • 전화 통화의 상대 언어를 음성으로 번역할 때
  • FaceTime에서 번역 자막을 보며 대화할 때

설정하고 사용하는 순서

  1. Apple Intelligence와 사용할 언어가 지원되는지 확인합니다.
  2. 필요한 번역 언어가 기기에 내려받아져 있는지 확인합니다.
  3. 메시지 대화 정보에서 자동 번역 또는 번역 언어를 선택합니다.
  4. 전화나 FaceTime 통화에서 실시간 번역 옵션이 제공되면 켭니다.
  5. 중요한 금액·주소·계약 내용은 원문과 번역을 다시 확인합니다.

안전하고 편리하게 사용하는 팁

  • 짧고 명확한 문장으로 말하면 번역 정확도를 높이는 데 도움이 됩니다.
  • 개인정보와 민감한 통화는 기능의 데이터 처리 안내를 확인하세요.
  • 전문용어와 고유명사는 잘못 번역될 수 있습니다.

지원 기기와 주의사항

실시간 번역은 Apple Intelligence 호환 기기, iOS 26 이상 및 지원 언어·지역에서 제공됩니다.

중요: Apple 계정, 개인정보, 통화 녹음, 결제, 초기화와 통신서비스에 영향을 주는 작업은 화면 안내와 관련 법률을 확인하고 중요한 자료를 먼저 백업하세요.
