아이폰 암호 앱에서 저장된 비밀번호와 패스키 관리하기

웹사이트와 앱 로그인 정보를 암호화해 보관하고 Face ID로 자동 완성하며 보안 상태를 확인합니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 iPhone 모델, 국가·지역, 통신사, 언어와 iOS 버전에 따라 달라질 수 있습니다. 설정 앱의 검색창에서 기능 이름을 검색하면 현재 기기에서 제공되는 메뉴를 찾기 쉽습니다.

이럴 때 유용합니다

  • 사이트마다 다른 강력한 암호를 만들어 저장할 때
  • 비밀번호 대신 패스키로 안전하게 로그인할 때
  • 유출되거나 재사용된 암호를 찾아 변경할 때

설정하고 사용하는 순서

  1. 암호 앱을 열고 Face ID·Touch ID 또는 기기 암호로 인증합니다.
  2. 전체·패스키·코드·보안 항목에서 원하는 계정을 찾습니다.
  3. 새 로그인 정보를 추가하거나 저장된 암호를 편집합니다.
  4. 보안 항목에서 유출·재사용·취약한 암호 경고를 확인합니다.
  5. 가족이나 팀과 공유할 때는 신뢰하는 사람만 공유 그룹에 추가합니다.

안전하고 편리하게 사용하는 팁

  • Apple 계정에는 이중 인증과 신뢰할 수 있는 전화번호를 설정하세요.
  • 암호 앱 화면과 복사한 비밀번호를 다른 사람에게 보여주지 마세요.
  • 기기 변경 전 iCloud 암호 및 키체인 동기화 상태를 확인하세요.

지원 기기와 주의사항

암호 앱은 iOS 18 이상이며 이전 iOS에서는 설정의 암호 메뉴에서 관리합니다.

중요: Apple 계정, 개인정보, 통화 녹음, 결제, 초기화와 통신서비스에 영향을 주는 작업은 화면 안내와 관련 법률을 확인하고 중요한 자료를 먼저 백업하세요.
