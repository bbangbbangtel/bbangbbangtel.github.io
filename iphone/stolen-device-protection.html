아이폰 도난당한 기기 보호로 중요 설정 변경 막기

기기 암호를 훔쳐본 사람이 아이폰을 가져가도 중요 계정과 금융 정보 변경을 어렵게 만듭니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 iPhone 모델, 국가·지역, 통신사, 언어와 iOS 버전에 따라 달라질 수 있습니다. 설정 앱의 검색창에서 기능 이름을 검색하면 현재 기기에서 제공되는 메뉴를 찾기 쉽습니다.

이럴 때 유용합니다

  • 외부 활동이 많고 분실·도난 위험에 대비할 때
  • 암호 변경과 Apple 계정 로그아웃에 추가 보호를 적용할 때
  • 저장된 암호와 결제 수단을 생체 인증으로 보호할 때

설정하고 사용하는 순서

  1. 먼저 Face ID 또는 Touch ID와 나의 찾기가 설정되어 있는지 확인합니다.
  2. 설정 → Face ID 및 암호에서 도난당한 기기 보호를 찾습니다.
  3. 기능을 켜고 익숙한 장소 외 또는 항상 보안 지연을 적용할지 선택합니다.
  4. 중요 설정 변경 시 생체 인증과 보안 지연 동작을 이해합니다.
  5. 분실 시 다른 기기에서 나의 찾기로 분실 모드를 즉시 실행합니다.

안전하고 편리하게 사용하는 팁

  • 기능을 끄는 과정에도 보안 지연이 적용될 수 있으므로 판매 전 미리 준비하세요.
  • 집과 직장 같은 익숙한 위치 판단에는 위치 서비스가 사용될 수 있습니다.
  • 기기 암호를 다른 사람이 보는 앞에서 입력하지 않는 습관이 가장 중요합니다.

지원 기기와 주의사항

도난당한 기기 보호는 iOS 17.3 이상과 Face ID 또는 Touch ID 지원 기기에서 사용할 수 있습니다.

중요: Apple 계정, 개인정보, 통화 녹음, 결제, 초기화와 통신서비스에 영향을 주는 작업은 화면 안내와 관련 법률을 확인하고 중요한 자료를 먼저 백업하세요.
