아이폰 통화 중 음성 분리로 주변 소음 줄이기

통화 중 사용자의 목소리에 초점을 맞춰 주변의 바람·사람·매장 소음을 줄입니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 iPhone 모델, 국가·지역, 통신사, 언어와 iOS 버전에 따라 달라질 수 있습니다. 설정 앱의 검색창에서 기능 이름을 검색하면 현재 기기에서 제공되는 메뉴를 찾기 쉽습니다.

이럴 때 유용합니다

  • 시끄러운 매장이나 거리에서 통화할 때
  • 영상 통화에서 목소리를 더 또렷하게 전달할 때
  • 여러 사람이 있는 공간에서 주변 소음을 줄일 때

설정하고 사용하는 순서

  1. 지원되는 전화 또는 FaceTime 통화를 시작합니다.
  2. 통화 중 화면 오른쪽 상단에서 제어 센터를 엽니다.
  3. 전화 앱 제어 또는 마이크 모드를 선택합니다.
  4. 음성 분리를 선택하고 상대방에게 음질을 확인합니다.
  5. 주변 소리도 함께 전달해야 하면 표준 또는 와이드 스펙트럼으로 되돌립니다.

안전하고 편리하게 사용하는 팁

  • 아이폰을 입에 너무 가까이 대면 소리가 왜곡될 수 있습니다.
  • Bluetooth 이어폰 사용 시 마이크 입력 장치를 확인하세요.
  • 음성 분리가 모든 소음을 완전히 없애는 것은 아닙니다.

지원 기기와 주의사항

음성 분리 지원 범위는 iPhone 모델, 통화 앱과 iOS 버전에 따라 다릅니다.

중요: Apple 계정, 개인정보, 통화 녹음, 결제, 초기화와 통신서비스에 영향을 주는 작업은 화면 안내와 관련 법률을 확인하고 중요한 자료를 먼저 백업하세요.

함께 보면 좋은 기능

👥

NameDrop·연락처 포스터

명함을 입력하지 않고 연락처를 교환하고 상대방에게 보일 이름·사진·포스터를 직접 정합니다.

🌐

전화·메시지 실시간 번역

서로 다른 언어를 사용하는 사람과 통화하거나 메시지를 주고받을 때 번역을 함께 표시합니다.

⌨️

텍스트 대치

짧은 약어만 입력해 매장 주소·인사말·상담 안내처럼 자주 쓰는 긴 문장을 자동으로 완성합니다.
