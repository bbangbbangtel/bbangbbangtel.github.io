## GitHub Pages에 올리는 법
1. ZIP 파일을 풀고 모든 파일/폴더를 GitHub 저장소 최상단에 업로드합니다.
2. Settings → Pages → Deploy from a branch → main / root 선택.
3. 생성된 주소로 접속합니다.

## 처음 바꿀 부분
- assets/config.js : 전화번호, 카카오URL, 주소, 영업시간
- sitemap.xml / robots.txt : YOUR-DOMAIN.com 을 실제 도메인으로 변경
- index.html 및 각 페이지의 콘텐츠를 실제 최신 정보로 확장
