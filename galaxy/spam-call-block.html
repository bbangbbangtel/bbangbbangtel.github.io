갤럭시 스팸·광고전화 차단과 모르는 번호 관리 방법

반복되는 광고전화는 개별 번호를 차단하고, 지원 기기에서는 발신자 정보와 스팸 보호 기능을 활용할 수 있습니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 중요한 작업 전에는 자료를 백업하고 최신 소프트웨어인지 확인하세요.

이럴 때 유용합니다

  • 같은 광고번호가 반복해서 전화할 때
  • 연락처에 없는 번호의 발신자 정보를 확인하고 싶을 때
  • 의심스러운 전화를 받은 뒤 번호를 신고하거나 차단할 때

설정하고 사용하는 순서

  1. 전화 앱 → 최근기록에서 차단할 번호를 선택하고 상세정보 → 차단을 누릅니다.
  2. 전체 차단목록은 전화 앱 → 더보기 → 설정 → 수신 차단 또는 번호 차단에서 관리합니다.
  3. 지원되는 경우 전화 설정의 발신자 정보 및 스팸 보호 기능을 켭니다.
  4. 스팸으로 표시된 전화는 내용을 확인한 뒤 차단 또는 신고 기능을 선택합니다.
  5. 문자 앱에서도 의심스러운 대화를 열어 번호 차단 및 스팸 신고 메뉴를 확인합니다.
  6. 통신사에서 제공하는 스팸 차단 서비스도 함께 확인합니다.

안전하고 편리하게 사용하는 팁

  • 모르는 번호 전체 차단은 택배·병원·거래처 전화까지 놓칠 수 있으므로 신중하게 설정하세요.
  • 화면에 표시되는 발신자 정보와 스팸 판단이 항상 정확한 것은 아닙니다.
  • 금융기관이나 기관을 사칭한 전화는 표시된 번호로 다시 걸지 말고 공식 대표번호를 직접 확인하세요.

지원 여부와 주의사항

발신자 정보·스팸 보호는 모델, 국가와 통신사에 따라 제공되지 않거나 통신사 자체 서비스로 대체될 수 있습니다.

중요: 계정, SIM, 자료 이전, 초기화와 보안 설정은 개인정보와 통신서비스에 영향을 줄 수 있습니다. 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요.
