갤럭시 무선 배터리 공유로 버즈와 워치 충전하기

지원 갤럭시의 뒷면을 무선 충전 패드처럼 이용해 다른 Qi 호환 기기나 웨어러블을 충전합니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 외출 중 갤럭시 버즈나 워치 배터리가 부족할 때
  • 충전기가 하나뿐일 때 다른 무선 충전 기기에 전력을 나눌 때
  • 친구의 Qi 호환 휴대폰에 긴급하게 배터리를 공유할 때

설정하고 사용하는 순서

  1. 공유할 갤럭시의 배터리 잔량이 충분한지 확인합니다.
  2. 빠른 설정창에서 무선 배터리 공유를 켭니다.
  3. 두 기기의 케이스와 금속 물체를 제거하고 충전 코일 위치를 확인합니다.
  4. 충전할 기기를 갤럭시 뒷면 중앙에 맞춰 올립니다.
  5. 진동이나 충전 표시를 확인하고 완료되면 기기를 분리해 기능을 끕니다.

안전하고 편리하게 사용하는 팁

  • 두꺼운 케이스와 카드·자석은 충전을 방해하거나 발열을 높일 수 있습니다.
  • 유선 충전보다 느리고 에너지 손실이 있어 긴급 충전용으로 적합합니다.
  • 기기가 뜨거워지면 즉시 분리하고 식힌 뒤 다시 시도하세요.

지원 여부와 주의사항

무선 배터리 공유와 Qi 충전 호환 여부, 최소 배터리 설정은 모델에 따라 다릅니다.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.

함께 보면 좋은 기능

🎧

갤럭시 버즈 연결

버즈를 갤럭시와 연결해 배터리 상태를 확인하고 주변 소리·노이즈 캔슬링·터치 조작을 관리합니다.

🔊

Dolby Atmos

지원되는 스피커·이어폰과 콘텐츠에서 공간감 있는 소리를 들을 수 있도록 음향 효과를 조절합니다.

🎵

앱 소리 분리 재생

선택한 음악·영상 앱의 소리를 지정한 Bluetooth 기기로 보내 다른 앱의 소리와 출력 장치를 분리합니다.
