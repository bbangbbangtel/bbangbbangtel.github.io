갤럭시 앱 소리 분리 재생으로 음악만 블루투스로 보내기

선택한 음악·영상 앱의 소리를 지정한 Bluetooth 기기로 보내 다른 앱의 소리와 출력 장치를 분리합니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 매장 스피커에는 음악만 재생하고 알림은 휴대폰에서 들을 때
  • 차량 Bluetooth로 내비게이션 또는 음악 소리만 보낼 때
  • 특정 앱과 다른 앱의 출력 장치를 나누고 싶을 때

설정하고 사용하는 순서

  1. 사용할 Bluetooth 스피커나 차량 오디오를 갤럭시에 연결합니다.
  2. 설정에서 소리 및 진동 → 앱 소리 분리 재생을 엽니다.
  3. 기능을 켜고 소리를 분리할 앱을 선택합니다.
  4. 선택 앱의 출력 장치로 Bluetooth 기기 또는 휴대전화를 지정합니다.
  5. 앱을 실행해 선택한 장치에서만 소리가 나오는지 시험합니다.

안전하고 편리하게 사용하는 팁

  • 선택한 출력 장치는 현재 기본 출력 장치와 달라야 정상 작동합니다.
  • Bluetooth 연결이 끊기면 소리가 휴대폰으로 전환될 수 있어 음량을 확인하세요.
  • 여러 앱을 지원하는 경우 필요한 앱만 선택하면 관리가 쉽습니다.

지원 여부와 주의사항

앱과 오디오 장치에 따라 알림·통화·미디어 소리의 분리가 제한될 수 있습니다.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.
