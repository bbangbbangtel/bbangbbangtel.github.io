삼성 노트에서 PDF 불러와 필기하고 내보내기

계약서·강의자료·안내문 같은 PDF를 삼성 노트에서 열어 메모하고 표시한 뒤 공유할 수 있습니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • PDF 견적서나 안내문에 직접 표시하고 설명할 때
  • 강의자료와 회의자료에 필기 내용을 함께 보관할 때
  • 작성한 노트를 PDF나 이미지로 내보내야 할 때

설정하고 사용하는 순서

  1. 삼성 노트 앱을 열고 PDF 가져오기 아이콘 또는 메뉴를 선택합니다.
  2. 내 파일이나 클라우드에서 불러올 PDF를 선택합니다.
  3. 펜·형광펜·지우개 도구를 이용해 필요한 내용을 표시합니다.
  4. 페이지 목록과 검색 기능을 이용해 문서 내용을 확인합니다.
  5. 공유 또는 파일로 저장에서 PDF를 선택해 사본을 내보냅니다.

안전하고 편리하게 사용하는 팁

  • 원본 보존이 중요하면 불러오기 전에 PDF 사본을 만들어 두세요.
  • S펜 지원 기기에서는 펜 굵기와 색을 용도별로 정해 두면 편리합니다.
  • 암호화된 PDF는 불러오기나 편집이 제한될 수 있습니다.

지원 여부와 주의사항

PDF 가져오기·내보내기 메뉴와 편집 가능 범위는 삼성 노트 버전에 따라 달라집니다.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.
