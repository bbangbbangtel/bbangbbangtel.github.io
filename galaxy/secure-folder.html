갤럭시 기능 활용법

갤럭시 보안폴더로 사진과 앱을 안전하게 보호하기

업무용 자료나 개인 사진, 별도로 사용할 앱을 일반 화면과 분리된 잠금공간에서 관리할 수 있습니다.

먼저 확인하세요
갤럭시 메뉴 이름과 지원 기능은 모델, 국가, 통신사, 앱 및 One UI 버전에 따라 달라질 수 있습니다. 설정의 소프트웨어 업데이트와 Galaxy Store 앱 업데이트를 먼저 확인하세요.

이럴 때 유용합니다

  • 고객 서류나 업무용 파일을 일반 사진과 분리할 때
  • 개인 사진과 앱을 별도 비밀번호로 보호할 때
  • 같은 앱을 일반 영역과 보안 영역에서 분리해 사용할 때

설정하고 사용하는 순서

  1. 설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → 보안폴더를 선택합니다.
  2. 삼성 계정으로 로그인하고 PIN·비밀번호·패턴 등 잠금방식을 설정합니다.
  3. 보안폴더 안에서 파일 추가 또는 앱 추가를 눌러 필요한 항목을 넣습니다.
  4. 빠른 설정창의 보안폴더 버튼으로 앱 화면에서 아이콘을 숨기거나 다시 표시할 수 있습니다.
  5. 자동 잠금 시점과 삼성 계정을 이용한 잠금 재설정 허용 여부를 확인합니다.

더 편리하게 사용하는 팁

  • 보안폴더 삭제 전에 내부 파일을 밖으로 이동할지 반드시 확인하세요.
  • 클라우드에만 있는 파일은 먼저 기기에 내려받아야 이동할 수 있습니다.
  • 잠금 재설정을 미리 허용하지 않으면 비밀번호 분실 시 내부 자료를 복구하기 어려울 수 있습니다.

지원 여부와 주의사항

보안폴더는 지원 기기와 소프트웨어에서 제공되며 메뉴 경로는 버전에 따라 다를 수 있습니다. 삼성 계정과 기기 잠금 설정이 필요합니다.

정확성 안내: AI 변환·검색·번역 결과에는 오류가 있을 수 있습니다. 계약조건, 금액, 날짜, 주소와 개인정보처럼 중요한 내용은 원본과 공식 자료를 다시 확인하세요.
