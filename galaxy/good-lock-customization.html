갤럭시 Good Lock으로 잠금화면과 조작 방식 꾸미기

삼성 공식 맞춤 설정 앱과 모듈을 이용해 기본 설정에서 바꾸기 어려운 화면과 조작 방식을 세밀하게 변경합니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 잠금화면 시계와 바로가기를 세밀하게 배치할 때
  • 홈 화면·최근 앱·빠른 설정의 모양을 바꾸고 싶을 때
  • 한 손 제스처나 알림 표시 방식을 사용자 습관에 맞출 때

설정하고 사용하는 순서

  1. Galaxy Store에서 Good Lock을 검색해 제공자가 Samsung Electronics인지 확인하고 설치합니다.
  2. Good Lock을 열어 필요한 모듈의 설명과 지원 버전을 확인합니다.
  3. LockStar·Home Up·QuickStar·One Hand Operation+ 등 목적에 맞는 모듈을 설치합니다.
  4. 한 번에 하나씩 설정을 변경하고 실제 동작을 확인합니다.
  5. 문제가 생기면 해당 모듈을 끄거나 설정을 초기화한 뒤 다시 적용합니다.

안전하고 편리하게 사용하는 팁

  • One UI 업데이트 직후에는 일부 모듈 업데이트가 늦어질 수 있습니다.
  • 설정을 많이 바꾸기 전에 기존 화면을 캡처해 두면 복원할 때 편리합니다.
  • Galaxy Store의 공식 배포자와 권한 요청을 반드시 확인하세요.

지원 여부와 주의사항

Good Lock과 개별 모듈은 국가, 기기, One UI 버전에 따라 제공 여부와 기능이 다릅니다.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.

함께 보면 좋은 기능

🌙

야간 모드 촬영

빛이 부족한 실내나 야간에도 여러 장면을 합성해 더 밝고 또렷한 사진을 남길 수 있는 촬영 기능입니다.

🎞️

싱글 테이크

짧은 순간을 촬영하면 갤럭시가 장면을 분석해 사진·영상 등 여러 결과물을 만들어 주는 기능입니다.

👤

인물사진 모드

피사체와 배경을 구분해 배경을 흐리거나 다양한 효과를 적용하여 주인공을 돋보이게 촬영합니다.
