갤럭시 한 손 조작 모드로 큰 화면 편하게 사용하기

큰 화면 전체를 작은 창으로 줄여 한 손으로 위쪽 버튼과 메뉴까지 쉽게 누를 수 있도록 돕습니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 이동 중 한 손으로 휴대폰을 조작해야 할 때
  • 화면 상단의 버튼이나 알림 영역에 손이 닿기 어려울 때
  • 손이 작은 사용자가 대화면 모델을 편하게 사용하고 싶을 때

설정하고 사용하는 순서

  1. 설정에서 유용한 기능을 열고 한 손 조작 모드를 선택합니다.
  2. 기능을 켠 뒤 버튼 방식 또는 제스처 방식을 선택합니다.
  3. 버튼 방식은 홈 버튼을 두 번 누르고 제스처 방식은 화면 하단 가운데를 아래로 밉니다.
  4. 축소 화면 옆의 화살표를 눌러 왼쪽과 오른쪽 위치를 바꿉니다.
  5. 빈 공간을 누르거나 종료 동작을 실행해 전체 화면으로 돌아옵니다.

안전하고 편리하게 사용하는 팁

  • 내비게이션 방식에 따라 실행 동작이 달라지므로 안내 그림을 확인하세요.
  • 한 손 키보드 모드는 삼성 키보드 설정에서 별도로 조절할 수 있습니다.
  • 자주 오작동하면 제스처 대신 버튼 방식을 시험해 보세요.

지원 여부와 주의사항

폴더블·태블릿 및 일부 화면 상태에서는 한 손 조작 모드를 사용할 수 없을 수 있습니다.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.

함께 보면 좋은 기능

🕒

Always On Display

화면이 꺼진 상태에서도 시간과 알림 아이콘 등 필요한 정보를 간단히 확인할 수 있습니다.

🎨

Good Lock 꾸미기

삼성 공식 맞춤 설정 앱과 모듈을 이용해 기본 설정에서 바꾸기 어려운 화면과 조작 방식을 세밀하게 변경합니다.

🌙

야간 모드 촬영

빛이 부족한 실내나 야간에도 여러 장면을 합성해 더 밝고 또렷한 사진을 남길 수 있는 촬영 기능입니다.
