갤럭시 Smart View·Windows 연결로 큰 화면에서 활용하기

TV에는 휴대폰 화면을 크게 띄우고, Windows PC에서는 사진·알림·문자와 지원 앱을 연결해 사용할 수 있습니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 중요한 작업 전에는 자료를 백업하고 최신 소프트웨어인지 확인하세요.

이럴 때 유용합니다

  • 휴대폰 사진이나 영상을 TV로 함께 볼 때
  • PC에서 휴대폰 알림과 문자를 확인할 때
  • 휴대폰 사진을 Windows PC로 옮기거나 앱 화면을 볼 때

설정하고 사용하는 순서

  1. TV 연결은 휴대폰과 TV를 같은 Wi-Fi에 연결하고 빠른 설정창에서 Smart View를 선택합니다.
  2. 검색된 TV를 선택하고 휴대폰과 TV에 표시되는 연결 요청을 승인합니다.
  3. Windows 연결은 휴대폰의 설정 또는 빠른 설정창에서 Windows와 연결을 엽니다.
  4. PC의 휴대폰과 연결(Phone Link) 앱을 실행하고 같은 Microsoft 계정 또는 화면 안내에 따라 연결합니다.
  5. 사진·메시지·전화·알림·앱 중 사용할 항목의 권한을 필요한 범위로 허용합니다.
  6. 공용 TV나 PC에서 사용한 뒤 연결 기기 목록과 권한을 해제했는지 확인합니다.

안전하고 편리하게 사용하는 팁

  • Smart View는 화면 전체가 보일 수 있으므로 알림과 개인정보 노출을 주의하세요.
  • 저작권 보호 앱은 TV 미러링이나 화면 표시가 제한될 수 있습니다.
  • 회사나 공용 PC에는 휴대폰 연결과 계정 로그인을 남기지 않는 것이 안전합니다.

지원 여부와 주의사항

Smart View와 Link to Windows의 지원 기능은 휴대폰·TV·PC 모델, 운영체제, 네트워크와 앱 정책에 따라 다릅니다.

중요: 계정, SIM, 자료 이전, 초기화와 보안 설정은 개인정보와 통신서비스에 영향을 줄 수 있습니다. 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요.

함께 보면 좋은 기능

📶

eSIM·듀얼 SIM

지원 기기에서는 물리 USIM과 디지털 eSIM을 함께 사용해 업무용과 개인용 번호를 한 휴대폰에서 관리할 수 있습니다.

🛠️

수리모드

서비스센터에 휴대폰을 맡길 때 개인자료를 노출하지 않으면서 기기 점검에 필요한 기본 기능만 사용할 수 있게 합니다.

📄

문서 스캔·글자 복사

별도 스캐너 없이 견적서나 안내문을 카메라로 촬영해 테두리를 맞춘 문서 이미지 또는 PDF로 보관할 수 있습니다.
