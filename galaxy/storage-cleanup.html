갤럭시 저장공간 확인하고 큰 파일과 중복 자료 정리하기

사진·영상·다운로드·앱이 차지하는 용량을 확인하고 불필요한 파일을 안전하게 정리합니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 사진 촬영이나 앱 설치 중 저장공간 부족 안내가 나올 때
  • 어떤 종류의 파일이 용량을 많이 차지하는지 확인할 때
  • 새 휴대폰으로 이동하기 전에 불필요한 자료를 정리할 때

설정하고 사용하는 순서

  1. 설정에서 디바이스 케어 → 저장공간을 열어 항목별 사용량을 확인합니다.
  2. 내 파일 앱의 저장공간 분석에서 큰 파일·중복 파일·다운로드 항목을 살펴봅니다.
  3. 삭제할 파일을 열어 필요한 자료인지 직접 확인합니다.
  4. 갤러리와 내 파일의 휴지통을 확인하고 복원이 필요 없는 항목만 비웁니다.
  5. 사용하지 않는 앱은 앱 정보와 저장 데이터의 필요 여부를 확인한 뒤 삭제합니다.

안전하고 편리하게 사용하는 팁

  • 사진과 문서는 PC나 클라우드에 백업한 뒤 삭제하는 것이 안전합니다.
  • 캐시 삭제와 데이터 삭제는 다르므로 앱 데이터 삭제는 신중하게 선택하세요.
  • 메신저의 사진·동영상은 앱 내부 저장공간 관리도 함께 확인하세요.

지원 여부와 주의사항

휴지통을 비우거나 앱 데이터를 삭제하면 복구하기 어려울 수 있으므로 백업을 먼저 확인하세요.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.
