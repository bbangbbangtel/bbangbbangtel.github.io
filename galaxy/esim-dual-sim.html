갤럭시 eSIM·듀얼 SIM으로 번호 2개 사용하는 방법

지원 기기에서는 물리 USIM과 디지털 eSIM을 함께 사용해 업무용과 개인용 번호를 한 휴대폰에서 관리할 수 있습니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 중요한 작업 전에는 자료를 백업하고 최신 소프트웨어인지 확인하세요.

이럴 때 유용합니다

  • 개인번호와 업무번호를 한 휴대폰에서 사용할 때
  • 해외여행용 데이터 eSIM을 추가할 때
  • 물리 USIM 없이 통신사 eSIM을 개통할 때

설정하고 사용하는 순서

  1. 사용 중인 갤럭시 모델과 이동통신사가 eSIM을 지원하는지 먼저 확인합니다.
  2. 통신사에서 eSIM을 개통하고 QR코드 또는 간편설정 정보를 준비합니다.
  3. 설정 → 연결 → SIM 관리자 → eSIM 추가를 선택합니다.
  4. 통신사에서 받은 QR코드를 스캔하거나 안내된 방식으로 요금제를 내려받습니다.
  5. SIM 관리자에서 통화·문자·모바일 데이터에 사용할 기본 SIM을 정합니다.
  6. 두 번호로 각각 전화와 문자를 시험하고 데이터 전환 및 로밍 설정을 확인합니다.

안전하고 편리하게 사용하는 팁

  • eSIM 삭제 후 다시 내려받을 때 통신사 절차나 비용이 발생할 수 있으므로 임의로 삭제하지 마세요.
  • 듀얼 SIM의 동시 대기와 데이터 사용 방식은 모델·통신사에 따라 다릅니다.
  • 해외 eSIM을 사용할 때 국내 회선의 데이터 로밍이 켜져 있지 않은지 확인하세요.

지원 여부와 주의사항

eSIM은 국가, 통신사, 출시 지역과 모델에 따라 지원 여부가 다릅니다. 개통·재발급·번호이동·기기변경 조건과 비용은 이용할 통신사에 확인해야 합니다.

중요: 계정, SIM, 자료 이전, 초기화와 보안 설정은 개인정보와 통신서비스에 영향을 줄 수 있습니다. 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요.
