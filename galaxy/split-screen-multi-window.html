갤럭시 촬영 · 화면 활용

갤럭시 화면 분할과 팝업 화면으로 앱 두 개 사용하기

동영상과 메모, 지도와 메시지처럼 두 개 이상의 앱을 한 화면에서 동시에 사용할 수 있는 기능입니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 영상을 보면서 메시지를 보내거나 메모할 때
  • 상품 정보를 확인하면서 계산기나 인터넷을 함께 사용할 때
  • 넓은 폴드 화면에서 여러 업무를 동시에 처리할 때

설정하고 사용하는 순서

  1. 최근 앱 버튼을 누르거나 제스처로 최근 앱 화면을 엽니다.
  2. 사용할 앱 위쪽의 앱 아이콘을 누릅니다.
  3. 분할 화면으로 열기 또는 팝업 화면으로 보기를 선택합니다.
  4. 두 번째로 사용할 앱을 목록에서 선택합니다.
  5. 가운데 구분선을 움직여 화면 크기를 조절하고 자주 쓰는 조합은 앱 페어로 저장합니다.

안전하고 편리하게 사용하는 팁

  • 엣지 패널의 앱 목록에서 앱을 끌어 놓는 방법도 편리합니다.
  • 팝업 창은 크기와 투명도를 조절하거나 작은 아이콘으로 접을 수 있습니다.
  • 일부 앱은 보안이나 화면 구성 때문에 분할 실행을 지원하지 않습니다.

지원 여부와 주의사항

멀티윈도우 동작 방식과 앱 페어 저장 위치는 기기 형태와 One UI 버전에 따라 달라집니다.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.

함께 보면 좋은 기능

📑

엣지 패널

현재 화면을 벗어나지 않고 가장자리 손잡이를 밀어 자주 쓰는 앱과 도구를 빠르게 실행합니다.

👍

한 손 조작 모드

큰 화면 전체를 작은 창으로 줄여 한 손으로 위쪽 버튼과 메뉴까지 쉽게 누를 수 있도록 돕습니다.

🕒

Always On Display

화면이 꺼진 상태에서도 시간과 알림 아이콘 등 필요한 정보를 간단히 확인할 수 있습니다.
