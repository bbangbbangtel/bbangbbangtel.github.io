갤럭시 촬영 · 화면 활용

갤럭시 프로 카메라 모드에서 ISO·셔터·화이트밸런스 조절하기

자동 촬영 대신 밝기·셔터 속도·초점·색온도를 직접 조절해 원하는 분위기의 사진을 만드는 기능입니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 자동 모드에서 사진이 너무 밝거나 어둡게 나올 때
  • 움직이는 대상의 순간을 멈추거나 빛의 궤적을 표현할 때
  • 조명에 따라 달라지는 사진의 색감을 직접 맞추고 싶을 때

설정하고 사용하는 순서

  1. 카메라 앱의 더보기에서 프로를 선택합니다.
  2. ISO를 낮추면 노이즈가 줄고 높이면 어두운 곳에서 밝아지는 원리를 확인합니다.
  3. 셔터 속도를 빠르게 하면 움직임이 정지되고 느리게 하면 빛과 움직임이 길게 표현됩니다.
  4. WB에서 색온도를, MF에서 초점 위치를 필요한 만큼 조절합니다.
  5. 노출계와 미리보기를 확인하면서 촬영하고 자동 모드 결과와 비교합니다.

안전하고 편리하게 사용하는 팁

  • 느린 셔터를 사용할 때는 삼각대가 필요합니다.
  • 처음에는 ISO와 셔터 중 하나만 조절하고 나머지는 자동으로 두는 것이 쉽습니다.
  • RAW 저장을 지원하는 모델은 후보정용 원본도 함께 남길 수 있습니다.

지원 여부와 주의사항

프로 모드의 항목과 지원 렌즈, RAW 저장 여부는 모델에 따라 다릅니다.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.
