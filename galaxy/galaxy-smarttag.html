갤럭시 스마트태그로 열쇠와 가방 위치 찾기

열쇠·가방 등 자주 잃어버리는 물건에 태그를 부착하고 SmartThings Find에서 위치를 확인합니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 집 안에서 열쇠나 가방을 어디에 두었는지 찾을 때
  • 여행 가방의 마지막 확인 위치를 살펴볼 때
  • 지원 모델에서 가까운 태그의 방향과 거리를 확인할 때

설정하고 사용하는 순서

  1. SmartTag의 버튼을 눌러 전원을 활성화하고 갤럭시 가까이에 둡니다.
  2. SmartThings 앱에서 나타나는 기기 추가 안내를 선택합니다.
  3. 삼성 계정과 장소·방 정보를 확인하고 등록을 완료합니다.
  4. 물건을 찾을 때 SmartThings Find에서 지도·주변 탐색·소리 울리기를 사용합니다.
  5. 배터리 잔량을 확인하고 교체하거나 다른 사람에게 넘기기 전 계정에서 삭제합니다.

안전하고 편리하게 사용하는 팁

  • 태그 이름에 열쇠·가방처럼 부착한 물건을 적어 두면 구분하기 쉽습니다.
  • UWB 방향 찾기는 지원 갤럭시와 태그 조합에서만 사용할 수 있습니다.
  • 위치 정보는 주변 기기와 네트워크 환경에 따라 지연되거나 오차가 있을 수 있습니다.

지원 여부와 주의사항

사람을 몰래 추적하는 용도로 사용하면 안 되며 관련 법률과 상대방의 사생활을 존중해야 합니다.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.

함께 보면 좋은 기능

🔋

무선 배터리 공유

지원 갤럭시의 뒷면을 무선 충전 패드처럼 이용해 다른 Qi 호환 기기나 웨어러블을 충전합니다.

🎧

갤럭시 버즈 연결

버즈를 갤럭시와 연결해 배터리 상태를 확인하고 주변 소리·노이즈 캔슬링·터치 조작을 관리합니다.

🔊

Dolby Atmos

지원되는 스피커·이어폰과 콘텐츠에서 공간감 있는 소리를 들을 수 있도록 음향 효과를 조절합니다.
