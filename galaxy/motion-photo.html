갤럭시 촬영 · 화면 활용

갤럭시 모션 포토로 촬영 전후 순간까지 저장하기

사진 한 장과 함께 촬영 직전의 짧은 움직임을 저장해 놓친 표정이나 순간을 다시 확인할 수 있습니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 아이·반려동물의 순간적인 표정을 놓치지 않고 싶을 때
  • 단체사진에서 눈을 감지 않은 장면을 확인할 때
  • 사진 앞뒤의 짧은 분위기와 소리를 함께 남기고 싶을 때

설정하고 사용하는 순서

  1. 카메라 앱을 열고 상단 또는 빠른 설정의 모션 포토 아이콘을 켭니다.
  2. 일반 사진처럼 구도를 잡고 촬영 버튼을 누릅니다.
  3. 갤러리에서 촬영한 사진을 열고 모션 포토 보기 또는 재생을 선택합니다.
  4. 원하는 순간에서 캡처 또는 프레임 저장 기능을 선택합니다.
  5. 공유할 때는 사진·동영상·GIF 등 제공되는 저장 형식을 확인합니다.

안전하고 편리하게 사용하는 팁

  • 촬영 전부터 휴대폰을 안정적으로 들고 있어야 앞부분도 선명합니다.
  • 일반 사진보다 저장공간을 더 사용할 수 있어 용량을 확인하세요.
  • 메신저로 전송하면 정지 사진으로만 전달될 수 있으므로 공유 형식을 확인하세요.

지원 여부와 주의사항

메뉴 위치와 소리 저장 여부, 프레임 추출 기능은 모델과 갤러리 버전에 따라 다릅니다.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.

화면 분할·멀티윈도우

동영상과 메모, 지도와 메시지처럼 두 개 이상의 앱을 한 화면에서 동시에 사용할 수 있는 기능입니다.

엣지 패널

현재 화면을 벗어나지 않고 가장자리 손잡이를 밀어 자주 쓰는 앱과 도구를 빠르게 실행합니다.

👍

한 손 조작 모드
