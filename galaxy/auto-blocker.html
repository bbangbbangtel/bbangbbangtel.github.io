갤럭시 자동 차단 기능으로 의심스러운 앱 설치 막기

공식 앱 스토어 밖의 앱 설치와 USB를 통한 의심스러운 명령 등 보안 위험을 줄이는 보호 기능입니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 문자 링크를 통해 받은 APK 설치 위험을 줄이고 싶을 때
  • USB 연결 중 의심스러운 명령 실행을 제한하고 싶을 때
  • 가족의 휴대폰을 기본 보안 설정으로 보호할 때

설정하고 사용하는 순서

  1. 설정에서 보안 및 개인정보 보호를 엽니다.
  2. 자동 차단 기능을 선택하고 설명과 제한되는 항목을 확인합니다.
  3. 자동 차단 기능을 켜고 추가 보호 옵션이 있으면 필요한 수준을 선택합니다.
  4. 정상적인 앱 설치나 USB 작업이 막히면 출처와 안전성을 먼저 확인합니다.
  5. 작업 후 보안을 위해 자동 차단 기능을 다시 켜 두었는지 확인합니다.

안전하고 편리하게 사용하는 팁

  • 앱은 Galaxy Store나 Google Play처럼 신뢰할 수 있는 스토어에서 설치하세요.
  • 택배·과태료·청첩장 등을 사칭한 APK 설치 링크는 누르지 않는 것이 안전합니다.
  • 보안 업데이트와 Google Play 시스템 업데이트를 함께 최신 상태로 유지하세요.

지원 여부와 주의사항

자동 차단의 세부 항목과 최대 제한 기능은 모델과 One UI 버전에 따라 다릅니다.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.
