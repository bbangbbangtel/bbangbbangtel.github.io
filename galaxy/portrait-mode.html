갤럭시 인물사진 모드로 배경 흐림 효과 조절하기

피사체와 배경을 구분해 배경을 흐리거나 다양한 효과를 적용하여 주인공을 돋보이게 촬영합니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 사람의 얼굴을 중심으로 자연스러운 프로필 사진을 찍을 때
  • 반려동물이나 사물을 배경과 분리해 표현할 때
  • 촬영 후 배경 흐림 정도와 효과를 다시 조절하고 싶을 때

설정하고 사용하는 순서

  1. 카메라 앱에서 인물사진을 선택합니다.
  2. 피사체와 적당한 거리를 두고 화면 안내에 맞춰 위치를 조절합니다.
  3. 배경 효과 아이콘을 눌러 흐림 정도나 지원되는 효과를 선택합니다.
  4. 초점이 얼굴 또는 원하는 대상에 맞았는지 확인한 뒤 촬영합니다.
  5. 갤러리에서 사진을 열고 배경 효과 변경 기능이 보이면 강도와 효과를 다시 조절합니다.

안전하고 편리하게 사용하는 팁

  • 피사체와 배경 사이의 거리가 멀수록 분리 효과가 자연스럽습니다.
  • 머리카락이나 투명한 물체 주변은 밝은 배경보다 단순한 배경이 유리합니다.
  • 어두운 곳에서는 야간 인물사진 지원 여부를 확인하세요.

지원 여부와 주의사항

인식 가능한 대상과 배경 효과 종류는 모델 및 카메라 렌즈에 따라 다릅니다.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.

프로 카메라 모드

자동 촬영 대신 밝기·셔터 속도·초점·색온도를 직접 조절해 원하는 분위기의 사진을 만드는 기능입니다.
