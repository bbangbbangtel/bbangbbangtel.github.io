갤럭시 S펜 에어 커맨드와 꺼진 화면 메모 사용하기

S펜 지원 갤럭시에서 펜을 꺼내면 표시되는 바로가기 메뉴로 메모와 화면 선택 작업을 빠르게 시작합니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 화면을 켜고 앱을 찾지 않고 바로 메모할 때
  • 화면 일부를 선택해 저장하거나 글자를 추출할 때
  • 현재 화면을 캡처한 뒤 설명을 직접 적을 때

설정하고 사용하는 순서

  1. 설정에서 유용한 기능 → S펜을 열어 에어 커맨드와 꺼진 화면 메모를 확인합니다.
  2. S펜을 꺼내거나 펜 아이콘을 눌러 에어 커맨드를 엽니다.
  3. 새 노트 작성·AI 선택·캡처 후 쓰기 등 필요한 메뉴를 선택합니다.
  4. 바로가기 추가에서 자주 쓰는 기능과 앱을 등록합니다.
  5. 화면이 꺼진 상태에서 S펜을 꺼내 메모하고 저장 위치를 확인합니다.

안전하고 편리하게 사용하는 팁

  • S펜을 두고 이동했을 때 알림 기능을 켜 두면 분실 예방에 도움이 됩니다.
  • 에어 액션은 모든 S펜과 모델에서 지원되는 기능이 아닙니다.
  • 펜촉에 이물질이 있으면 화면 손상을 막기 위해 먼저 확인하세요.

지원 여부와 주의사항

S펜 지원 범위, 블루투스 에어 액션과 제스처 기능은 모델별로 크게 다릅니다.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.
