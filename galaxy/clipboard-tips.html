갤럭시 클립보드에서 복사한 글과 이미지 다시 사용하기

최근 복사한 여러 개의 문장과 이미지를 임시 보관해 필요한 내용을 다시 찾아 붙여넣을 수 있습니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 주소·계좌·상담 문구처럼 반복 입력하는 내용을 사용할 때
  • 바로 전에 복사한 여러 문장 중 하나를 다시 찾을 때
  • 자주 쓰는 문장을 고정해 빠르게 붙여넣을 때

설정하고 사용하는 순서

  1. 문자나 메모의 입력칸을 눌러 삼성 키보드를 엽니다.
  2. 키보드 도구 모음의 클립보드를 선택하고 보이지 않으면 더보기를 누릅니다.
  3. 목록에서 원하는 글이나 이미지를 눌러 입력합니다.
  4. 자주 사용하는 항목은 길게 눌러 고정 기능이 제공되면 선택합니다.
  5. 개인정보가 포함된 항목은 선택 삭제하거나 클립보드 전체를 정리합니다.

안전하고 편리하게 사용하는 팁

  • 비밀번호·신분증 번호·계좌정보는 클립보드에 오래 남기지 마세요.
  • 화면 캡처를 클립보드에 저장하는 옵션은 키보드 설정에서 확인할 수 있습니다.
  • 앱에 따라 이미지 붙여넣기가 지원되지 않을 수 있습니다.

지원 여부와 주의사항

클립보드 기록 길이와 고정·동기화 기능은 키보드 및 One UI 버전에 따라 다릅니다.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.

함께 보면 좋은 기능

🛡️

자동 차단 기능

공식 앱 스토어 밖의 앱 설치와 USB를 통한 의심스러운 명령 등 보안 위험을 줄이는 보호 기능입니다.

🔏

앱 권한 관리

앱마다 개인정보와 기기 기능에 접근할 수 있는 범위를 확인하고 사용 중에만 허용하거나 차단합니다.

🔔

알림 기록 확인

알림 기록을 미리 켜 두면 알림창에서 지워 버린 최근 알림을 앱별로 다시 확인할 수 있습니다.
