갤럭시 모바일 데이터 사용량 확인하고 경고·한도 설정하기

월별 모바일 데이터 사용량과 많이 사용하는 앱을 확인하고 경고 또는 차단 기준을 설정합니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 제공량이 정해진 요금제에서 데이터 초과를 예방할 때
  • 어떤 앱이 백그라운드에서 데이터를 많이 쓰는지 찾을 때
  • 해외나 로밍 중 불필요한 데이터 사용을 줄일 때

설정하고 사용하는 순서

  1. 설정에서 연결 → 데이터 사용을 엽니다.
  2. 모바일 데이터 사용량에서 기간과 앱별 사용량을 확인합니다.
  3. 청구 주기 및 데이터 경고 메뉴에서 요금제 기준일을 맞춥니다.
  4. 데이터 경고와 사용 한도를 필요한 용량으로 설정합니다.
  5. 사용량이 많은 앱은 앱을 선택해 백그라운드 데이터 허용 여부를 조절합니다.

안전하고 편리하게 사용하는 팁

  • 휴대폰 측정값과 통신사 청구 기준에는 차이가 있을 수 있습니다.
  • 자동 업데이트와 클라우드 백업은 Wi-Fi에서만 실행하도록 설정할 수 있습니다.
  • 데이터 절약 모드를 켜면 일부 앱의 실시간 알림이 늦어질 수 있습니다.

지원 여부와 주의사항

정확한 잔여량과 과금은 반드시 이용 중인 통신사 앱이나 고객센터에서 확인하세요.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.
