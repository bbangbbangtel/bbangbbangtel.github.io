갤럭시 S펜 손글씨를 텍스트로 변환하기

키보드 대신 화면에 직접 쓴 글씨를 인식해 검색·복사하기 쉬운 일반 문자로 바꿔 줍니다.

먼저 확인하세요
메뉴 이름과 지원 기능은 갤럭시 모델, 국가, 통신사, 연결 기기와 One UI 버전에 따라 달라질 수 있습니다. 설정을 변경하기 전에 현재 상태와 중요한 자료를 확인하세요.

이럴 때 유용합니다

  • 회의나 상담 중 빠르게 손글씨로 메모할 때
  • 작성한 필기 내용을 문자·메일·문서에 복사할 때
  • 검색 가능한 노트로 정리하고 싶을 때

설정하고 사용하는 순서

  1. 설정에서 유용한 기능 → S펜 → S펜으로 텍스트 입력을 켭니다.
  2. 삼성 노트에서 손글씨 모드로 내용을 작성합니다.
  3. 선택 도구로 변환할 손글씨 영역을 지정합니다.
  4. 텍스트로 변환을 선택하고 인식된 문장을 확인합니다.
  5. 틀린 글자를 수정한 뒤 복사하거나 노트에 변환 결과를 삽입합니다.

안전하고 편리하게 사용하는 팁

  • 글자 사이를 적당히 띄우고 한 줄을 곧게 쓰면 인식률이 좋아집니다.
  • 사용 언어가 설치되어 있는지 삼성 키보드 언어 설정을 확인하세요.
  • 주소나 숫자처럼 중요한 내용은 원본과 변환 결과를 반드시 비교하세요.

지원 여부와 주의사항

S펜 지원 기기와 삼성 노트·키보드 버전에 따라 변환 방식과 지원 언어가 다릅니다.

중요: 휴대폰 설정, 계정, 개인정보, 결제, 네트워크와 관련된 기능은 화면 안내를 확인하고 중요한 자료를 먼저 백업하세요. 실제 메뉴가 다르면 설정 검색창에서 기능 이름을 검색해 보세요.
