어떤 휴대폰에서 어떤 휴대폰으로 바꾸더라도 걱정하지 마세요. 아래 실제 화면과 같은 버튼을 순서대로 누르면 됩니다.

먼저 준비하세요

  • 두 휴대폰을 충분히 충전하거나 충전기에 연결합니다.
  • 새 휴대폰의 저장 공간이 충분한지 확인합니다.
  • Wi-Fi를 켜고 Smart Switch와 운영체제를 업데이트합니다.
  • 삼성·구글·Apple 계정 비밀번호를 준비합니다.
  • 카카오톡은 앱에서 대화를 한 번 더 백업합니다.
  • 모든 자료를 확인하기 전 기존 폰을 초기화하지 않습니다.
GUIDE 01 · SMART SWITCH

갤럭시에서 갤럭시로

기존 갤럭시와 새 갤럭시를 가까이 두고 무선으로 옮기는 방법입니다.

삼성 공식 안내 보기 ↗
💡
새 갤럭시 화면을 기준으로 진행합니다. 두 휴대폰 모두 Smart Switch를 최신 버전으로 업데이트해 주세요.
새 갤럭시

데이터 받기 선택

Smart Switch에서 이 휴대전화에서 받기를 누릅니다.

새 갤럭시

갤럭시·안드로이드 선택

이전 기기 종류에서 Galaxy/Android를 누른 다음 무선을 선택합니다.

두 휴대폰 연결

QR 코드 스캔

기존 갤럭시에서 이 휴대전화에서 보내기 → 무선을 누르고 새 폰의 QR 코드를 스캔합니다.

기존 갤럭시

연결 허용

기존 폰에 연결할까요?가 표시되면 연결을 누르고 잠시 기다립니다.

새 갤럭시

가져올 자료 선택

모두 또는 직접 설정을 선택합니다. 사진·연락처·문자·앱 등을 확인한 뒤 다음을 누릅니다.

전송 중

두 휴대폰 그대로 두기

진행률이 100%가 될 때까지 두 휴대폰을 가까이 두고 다른 앱을 사용하지 않습니다.

완료

전송 결과 확인

데이터 가져오기 모두 완료가 나오면 연락처와 사진을 확인합니다.

카카오톡 주의: 갤럭시끼리는 조건을 충족하면 Smart Switch로 대화와 미디어를 옮길 수 있습니다. 새 폰에 카카오톡이 먼저 설치되어 있다면 삭제한 뒤 전송하고, 안전을 위해 카카오톡 앱의 대화 백업도 함께 진행하세요.
GUIDE 02 · 빠른 시작

아이폰에서 아이폰으로

기존 아이폰을 이용해 새 아이폰을 자동으로 설정하고 데이터를 직접 전송합니다.

Apple 공식 안내 보기 ↗
💡
기존 아이폰의 Wi-Fi와 Bluetooth를 켭니다. 두 아이폰을 충전기에 연결하고 바로 옆에 두세요.
새 아이폰

새 아이폰 켜기

안녕하세요 화면을 위로 쓸어 올리고 언어와 대한민국을 선택합니다.

새 아이폰

빠른 시작 화면 확인

기존 아이폰을 가까이 두면 자동으로 인식됩니다. 기존 폰에 나타난 계속을 누릅니다.

두 아이폰

화면 인증 후 암호 입력

기존 아이폰 카메라로 새 아이폰의 움직이는 이미지를 맞춘 뒤, 새 아이폰에 기존 아이폰의 잠금 암호를 입력합니다.

새 아이폰

전송 방법 선택

두 기기가 모두 있다면 iPhone에서 직접 전송을 선택합니다. 백업을 이용할 때는 iCloud를 선택합니다.

새 아이폰

Apple 계정 확인

Apple 계정 암호나 기존 기기에 표시된 확인 코드를 입력하고 화면 안내를 계속합니다.

전송 완료

진행 막대 끝까지 기다리기

두 아이폰을 가까이 두고 충전한 상태에서 진행 막대가 끝나면 사진, 연락처, 메시지, 카카오톡을 확인합니다.

SIM·eSIM 주의: 물리 SIM은 새 아이폰으로 옮기고, eSIM은 화면에 ‘근처에 있는 iPhone에서 전송’이 표시될 때 진행합니다. 통신사에 따라 재발급이 필요할 수 있습니다.
GUIDE 03 · 케이블 연결

아이폰에서 갤럭시로

아이폰 케이블을 새 갤럭시에 연결해 사진·연락처·문자·일정 등을 옮깁니다.

삼성 공식 안내 보기 ↗
💡
가장 안정적인 케이블 방식입니다. iPhone 15 이후는 USB-C 케이블, 이전 아이폰은 USB-C-Lightning 케이블 또는 커넥터를 사용합니다.
아이폰

아이폰 준비

아이폰 잠금을 해제하고 케이블을 준비합니다. iCloud 사진은 가능하면 원본을 내려받습니다.

새 갤럭시

Smart Switch 실행

설정 → 계정 및 백업 → 이전 기기에서 데이터 가져오기로 들어갑니다.

새 갤럭시

데이터 받기 선택

데이터 받기 또는 이 휴대전화에서 받기를 누릅니다.

새 갤럭시

iPhone·iPad 선택

이전 기기 종류에서 iPhone/iPad를 선택합니다.

새 갤럭시

아이폰 연결 확인

화면에 표시된 케이블 모양을 확인하고 케이블 연결 방식을 선택합니다.

두 휴대폰

케이블 연결

아이폰 데이터 케이블을 갤럭시의 USB-C 포트 또는 커넥터에 연결합니다.

아이폰

신뢰 선택

아이폰에 이 컴퓨터를 신뢰하겠습니까?가 나오면 신뢰를 누르고 암호를 입력합니다.

새 갤럭시

아이폰 확인 후 다음

iPhone 확인하기 화면에서 연결 상태를 확인한 뒤 다음을 누릅니다.

검색 중

가져올 자료 검색

Smart Switch가 아이폰의 사진과 연락처 등을 분석할 때까지 기다립니다.

새 갤럭시

자료 선택 후 전송

연락처·메시지·사진·동영상·일정 등을 선택하고 전송을 누릅니다.

전송 중

케이블 분리 금지

전송이 끝날 때까지 아이폰 잠금을 해제한 상태로 두고 케이블을 분리하지 않습니다.

완료

전송 결과 확인

데이터 가져오기 완료가 나오면 사진과 연락처를 확인하고 케이블을 분리합니다.

꼭 확인하세요: 아이폰의 카카오톡 대화는 Smart Switch로 직접 옮겨지지 않으므로 카카오톡에서 별도 백업·복원해야 합니다. 이동 후에는 아이폰의 iMessage와 FaceTime을 끄고 갤럭시에서 문자 수신을 확인하세요.
GUIDE 04 · iOS로 이동

갤럭시에서 아이폰으로

새 아이폰을 처음 설정하는 동안 ‘iOS로 이동’을 이용하는 방법입니다.

Apple 공식 안내 보기 ↗
💡
새 아이폰이 ‘안녕하세요’ 초기 화면이어야 합니다. 이미 설정을 끝냈다면 초기화 후 다시 진행하거나 필요한 자료를 수동으로 옮겨야 합니다.
새 아이폰

다른 기기 없이 설정

새 아이폰의 빠른 시작 화면에서 다른 기기 없이 설정을 누릅니다.

새 아이폰

Android에서 선택

앱 및 데이터 전송 → Android에서 → 앱으로 전송을 누릅니다.

새 아이폰

일회용 코드 확인

아이폰에 표시되는 6자리 또는 10자리 코드를 확인합니다.

기존 갤럭시

iOS로 이동 앱 연결

갤럭시에서 iOS로 이동 앱을 열고 동의·권한 허용 후 아이폰의 코드 또는 QR로 연결합니다.

기존 갤럭시

전송할 자료 선택

연락처·메시지·사진·동영상·파일·통화기록·캘린더 등을 선택하고 계속을 누릅니다. 아이폰이 만든 임시 Wi-Fi 연결 요청도 허용합니다.

완료 확인

아이폰 진행 막대 확인

갤럭시에 완료가 먼저 표시되어도 아이폰의 진행 막대가 끝날 때까지 기다린 후 설정을 마칩니다.

옮겨지지 않는 항목: 일부 유료 앱, 음악, 전자책, PDF, 금융앱 인증서, 삼성월렛 카드는 별도로 설치하거나 등록해야 합니다. 카카오톡은 앱에서 대화 백업 후 새 아이폰에서 복원하세요.

기존 휴대폰을 초기화하기 전 최종 확인
